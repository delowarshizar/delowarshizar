## 👋 About Me

I'm a **Junior Software Engineer** who takes a feature from the database table to the button the user clicks.

I work at **WEB SOFT BD**, where I build responsive React interfaces and the Spring Boot REST APIs behind them. I'm a **Computer Science & Engineering graduate of Daffodil International University**, where I also worked on IoT projects as a Research Assistant. I like software that solves a real problem for a real person.

- 💼 **Now:** Jr. Software Engineer @ **WEB SOFT BD**
- 🔬 **Research:** Research Assistant @ Embedded System Research Center, DIU
- 🎓 **Education:** CSE, Daffodil International University
- 📍 **Based in:** Dhaka, Bangladesh
- 🌱 **Learning:** backend architecture and system design
- 🤝 **Open to:** collaboration on web and IoT projects
- 💬 **Ask me about:** React, Spring Boot, REST APIs, SQL
- 🌐 **Portfolio:** [delowarhusain.me](https://delowarhusain.me/)
